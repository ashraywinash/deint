1. **Enter Hive Shell:**

   hive

   _Starts the Hive command-line interface (CLI)._

2. **Create a database:**

   create database emp_detail;
   use emp_detail;

   _Creates and switches to a new database named `emp_detail`._

3. **Create a table:**

   create table emp(id int, ename string, job string, sal int, deptno int) row format delimited fields terminated by ',' stored as textfile;

   _Defines a table `emp` with fields separated by commas._

4. **Load data into table (with file):**

   load data local inpath 'employee.txt' into table emp;

   _Loads data from a local file into the `emp` table._

5. **Select all employee names:**

   select ename from emp;

   _Displays all employee names from the `emp` table._

6. **Select rows with name 'A':**

   select * from emp where ename='A';

   _Fetches all records where `ename` is 'A'._

7. **Count number of records:**

   select count(*) from emp;

   _Returns the total number of records in the table._

8. **Group salaries by department:**

   select deptno, sum(sal) from emp group by deptno;

   _Shows total salary grouped by department._

9. **Select salary range between 2000 and 5000:**

   select * from emp where sal between 2000 and 5000;

   _Fetches employees with salaries between 2000 and 5000._

10. **Job title of exactly 5 characters:**

   select ename from emp where job LIKE '_____';

   _Finds employees where the `job` has exactly 5 characters._

11. **Job with 'l' as second character:**

   select ename from emp where job LIKE '_l%';

   _Finds names of employees whose job has 'l' as the second character._

12. **Total salary per department:**

   select deptno, sum(sal) from emp group by deptno;

   _(Repeated) Displays sum of salaries per department._

13. **Add a column:**

   alter table emp add columns(lastname string);

   _Adds a new column `lastname` to the `emp` table._

14. **Rename the table:**

   alter table emp rename to emp1;

   _Renames the table from `emp` to `emp1`._

15. **Drop the table:**

   drop table emp;

   _Deletes the table `emp` from the database._
